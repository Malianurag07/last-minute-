# ISO/IEC 27001:2022 — readiness

**What can be certified:** ISO 27001 certifies a company's *Information Security Management System* (ISMS) — its people, processes and technology — not an app by itself. Certification is done by an accredited certification body in two audits (Stage 1: documents; Stage 2: evidence that controls run for a few months). Small teams typically take **4–9 months** from start to certificate.

The product side is ready: most *technological* controls of Annex A are already built in. The remaining work is mainly *organisational* (policies, risk register, training, supplier checks, internal audit).

## Organisational, people and physical controls (A.5–A.7) — to set up

- ISMS scope, information security policy, roles (name a security owner).
- Risk assessment & treatment plan; **Statement of Applicability** listing all 93 controls.
- Asset inventory (this repo, cloud accounts, laptops, SMS/hosting suppliers).
- Supplier security (A.5.19–5.22): DPAs and security checks for host, SMS, analytics.
- Incident management (A.5.24–5.28): see `docs/security/INCIDENT_RESPONSE.md`.
- Business continuity (A.5.29–5.30): backup restore drill, status page.
- Staff screening, NDA, yearly security & privacy training (A.6).
- Laptop encryption, screen lock, MDM (A.7/A.8.1).
- Internal audit and management review before the Stage 1 audit.

## Related standards worth considering

- **ISO/IEC 27701** (privacy extension of 27001) — pairs well with DPDPA.
- **OWASP ASVS L2 / MASVS L1** — target for the pentest.
- **SOC 2 Type II** — only if enterprise/B2B customers ask for it.
